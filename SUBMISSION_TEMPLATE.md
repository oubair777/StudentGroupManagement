## 🛠️ Tech Stack & Key Highlights

- **Frontend:** React.js, Vite, Tailwind CSS, Lucide Icons, Axios, React Router v6
- **Backend:** Node.js, Express.js, JWT Authentication (Role-based: Student vs Admin), bcryptjs
- **Database:** PostgreSQL (with Docker Compose, auto-migrations, indexing, and SQLite dev fallback)
- **Containerization:** Docker & Docker Compose (`docker-compose up --build`)
- **Key Features Implemented:**
  - Role-based JWT authentication (Student & Professor)
  - Student group creation and member invitation by Student Email or Student ID
  - Two-Step Verification workflow for OneDrive assignment submissions
  - Professor assignment creation with targeting (**All Students** or **Specific Groups**)
  - Group-wise & Student-wise submission confirmation tracker
  - Visual completion progress bars, performance ranking badges, and analytics dashboard
  - 1-Click quick demo credentials for seamless evaluator testing
